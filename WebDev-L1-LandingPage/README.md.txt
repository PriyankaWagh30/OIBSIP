# FocusFlow – Student Productivity Hub

A responsive and visually polished landing page designed to help students
organize their study routine, maintain focus, and track their productivity.

---

## 📌 About the Project

FocusFlow is a student-focused productivity landing page developed as part
of the Oasis Infobyte Web Development & Designing Internship – Level 1,
Task 1: Landing Page.

The project presents a clean and modern interface where students can
explore study goals, focus sessions, productivity tracking, and a simple
study workflow.

The main objective of this project is to demonstrate foundational
web development skills using HTML5 and CSS3.

---

## 🎯 Project Objective

The objective of FocusFlow is to create a responsive static landing page
that provides:

- A clear and engaging hero section
- Easy navigation between sections
- Student productivity features
- Study goals and progress visualization
- A simple "How It Works" workflow
- A clean and consistent user interface
- Responsive design for different screen sizes

---

## ✨ Key Features

### 🧭 Responsive Navigation
Navigation links provide easy access to the main sections of the website.

### 🎯 Hero Section
Introduces FocusFlow with a clear headline, description, and
call-to-action buttons.

### 📊 Productivity Dashboard
Displays sample productivity information such as daily goals,
focus time, study sessions, and weekly progress.

### 🚀 Productivity Features
Highlights important study productivity concepts including:

- Goal Setting
- Focus Sessions
- Progress Tracking

### 📚 Study Goals
Displays sample daily study goals with progress indicators.

### 🔄 How It Works
Presents a simple three-step workflow:

**Plan → Focus → Progress**

### ⏱️ Focus Timer Section
Includes a visual focus-timer interface designed for a
deep-work study session.

### ℹ️ About Section
Provides a brief introduction to the purpose of FocusFlow.

### 📱 Responsive Design
The layout is designed to adapt to desktop, tablet, and mobile
screen sizes.

---

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic content
- **CSS3** – Styling, layout, responsiveness, and visual design
- **CSS Flexbox** – Flexible page layouts
- **CSS Grid** – Structured content layouts

> JavaScript is not used in the current version of this Task 1 project.
