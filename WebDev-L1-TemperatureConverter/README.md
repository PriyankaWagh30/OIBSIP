# Temperature Converter Website

A simple and responsive temperature converter website developed using HTML, CSS, and JavaScript.

## 🌡️ Project Overview

This website allows users to convert temperatures between:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The project provides a simple, clean, and user-friendly interface for quick temperature conversions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Three separate result boxes
- Input validation
- Kelvin absolute-zero validation
- Responsive design
- Smooth navigation
- Interactive buttons and hover effects
